# 숏폼 메이커

뜨는 숏폼을 골라 **비슷하지만 다른 내 대본**으로 바꾸고, 그 대본으로 영상을 원클릭 제작하는 안드로이드 앱.

1. **고르기** — [short-form-report](https://github.com/happyfamily1984/short-form-report) 저장소가 매일 아침 모으는 인기 숏폼·숏드라마(한국·해외)를 홈에서 본다. 목록에 없는 영상은 유튜브 링크를 붙여 가져온다.
2. **내 것으로 바꾸기** — 원본의 훅·장면 순서·반전 자리는 살리고 인물·배경·사건·대사는 새로 쓴다 (Gemini). 닮은 정도, 내 소재, 길이, 결말을 고를 수 있다.
3. **나만의 등장인물** — 원본에 나온 사람·동물·캐릭터·사물의 종류는 지키고 생김새는 새로 만든다. 등장인물 이미지 프롬프트(전신·얼굴)를 만들고, "비슷하지만 다른 3안"으로 바꾸고, 내 캐릭터로 저장해 다음 영상에 다시 쓴다. 등장인물이 없는 영상은 없이 만든다.
4. **원클릭 제작** — 그록으로 장면 이미지, 클링으로 핵심 샷 영상을 만들고 내려받아 자막을 넣어 한 편으로 합친 뒤 업로드 화면으로 넘긴다.

## 구조

- `www/` 앱 본체 (기기 안에만 저장, 서버 없음)
  - `js/data.js` 영상 종류·카메라·스타일·안내 문구
  - `js/app.js` 화면·프롬프트·AI 호출·원클릭 제작
  - `js/kling.js` 자동 입력 기본 순서
- `android/` 안드로이드 래퍼 (웹뷰 + 접근성 자동 입력 + 영상 합치기)
- `kling/`, `grok/`, `pickle/` 자동 입력 순서 (앱 설정의 "순서 업데이트"로 다시 읽음, `kling/README.md` 참고)

AI 기능은 사용자가 설정에 넣은 Gemini API 키로 동작한다. "AI가 직접 보고 분석"은 유튜브 주소를 Gemini에 넘겨 영상을 실제로 보고 장면별 대본과 등장인물을 뽑는다.

## 빌드

```bash
cd android && ./gradlew assembleRelease   # keystore.properties 가 있으면 서명됨
```

서명 키(`*.jks`)와 `keystore.properties` 는 저장소에 올리지 않는다.
