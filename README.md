# 숏폼 메이커

교육·과학·다큐멘터리 분야에서 **잘 되는 쇼츠의 구성을 빌려 내 주제로 바꾸고**, 내레이션까지 넣어 원클릭으로 영상을 만드는 안드로이드 앱.

1. **고르기** — [short-form-report](https://github.com/happyfamily1984/short-form-report) 저장소가 매일 아침 모으는 교육·과학·다큐 인기 쇼츠(한국·해외)를 홈에서 본다. 목록에 없는 영상은 유튜브 링크를 붙이면 AI가 직접 보고 분석한다.
2. **내 주제로 바꾸기** — 원본의 훅·장면 순서·열린 고리·길이는 살리고 주제와 문장은 새로 쓴다 (Gemini). 닮은 정도는 같은 주제 / 비슷한 주제 / 구성만 빌리기.
3. **사실 확인** — AI가 대본 속 사실 주장을 검색어와 함께 뽑아 준다. 하나씩 검색해 체크한다.
4. **원클릭 제작** — 그록 장면 이미지 → 클링 핵심 샷 → 내레이션 음성(Gemini AI 목소리 또는 휴대폰 음성)과 자막을 넣어 한 편으로 합치기 → 업로드 화면.

진행자·마스코트 캐릭터(사람·동물·캐릭터·사물)는 선택이다. 대부분은 자료화면 같은 장면과 내레이션만으로 만든다.

## 구조

- `www/` 앱 본체 (기기 안에만 저장, 서버 없음)
  - `js/data.js` 영상 종류·카메라·스타일·안내 문구
  - `js/app.js` 화면·프롬프트·AI 호출·원클릭 제작
  - `js/kling.js` 자동 입력 기본 순서
- `android/` 안드로이드 래퍼 (웹뷰 + 접근성 자동 입력 + 영상 합치기)
- `kling/`, `grok/`, `pickle/` 자동 입력 순서 (앱 설정의 "순서 업데이트"로 다시 읽음, `kling/README.md` 참고)

AI 기능과 Gemini AI 목소리는 사용자가 설정에 넣은 Gemini API 키로 동작한다. 음성 모델은 설정의 "키 확인·모델"에서 자동으로 찾는다. "AI가 직접 보고 분석"은 유튜브 주소를 Gemini에 넘겨 영상을 실제로 보고 장면별 대본과 등장인물을 뽑는다.

## 빌드

```bash
cd android && ./gradlew assembleRelease   # keystore.properties 가 있으면 서명됨
```

서명 키(`*.jks`)와 `keystore.properties` 는 저장소에 올리지 않는다.

새 세션은 먼저 [docs/작업노트.md](docs/작업노트.md)를 읽는다 (정한 것, 하던 일, 서명 키, 빌드 방법).
