## 내레이션 TTS 조사 결과 (2026-11 기준, 약관은 바뀔 수 있음)

무료로 **수익 채널**에 쓸 수 있고 앱에서 부를 수 있는 것은 Gemini TTS, Google Cloud TTS 정도.

- 클로바더빙·타입캐스트·ElevenLabs 무료: 수익 채널 불가.
- Azure(SunHi·InJoon) 무료 F0: 상업 이용 근거 약함 (유료 S0 필요로 봄).
- Vrew: 상업 이용 허용, 출처 표기 불필요, API 없음. 2026-12-01 요금제 개편 예정.
- **Gemini TTS**: 앱에 넣음. 무료, 카드 불필요, 대신 입력이 Google 개선에 쓰일 수 있음. 무료 한도 숫자 미확인. 목소리 Charon·Kore·Orus·Aoede·Puck·Zephyr. 음성 모델 이름은 앱 설정의 "키 확인·모델"에서 이름에 `tts` 가 든 모델을 찾아 쓴다.
- Google Cloud TTS Chirp 3 HD: 한국어 30종, 월 100만 자 무료, 카드 등록 필요. 다음 후보로 남겨 둠.
- 휴대폰 기본 음성(Android TTS): 대체용으로 넣음.

## 하던 일 (이어서 할 것)

**초 단위 추출**: 사용자가 요청함. 리포트의 "영상 직접 보기" 단계에서 Gemini 가 영상을 1초 단위로 적게 한다.
- 추가할 필드: `timeline: [{s, visual, text(화면 글자), audio(내레이션 요지·효과음), cut(장면 전환 여부), prompt(그 장면을 다시 만드는 영어 프롬프트)}]`. 60초 넘는 영상은 2초 단위.
- 넣을 곳: `trends/scripts/analyze.py` 의 `WATCH_SCHEMA`·영상 직접 보기 프롬프트·`tidy_video`·`cur.update` 키 목록, 앱 `www/js/app.js` 의 `S_ANALYSIS`·`aiAnalyze`(링크로 가져온 영상)·`srcFrom`.
- 앱 쪽: 바꿔 쓰기 화면에 초 단위 분석과 평균 컷 길이를 보여 주고, `remixPrompt` 에 컷 리듬을 넘긴다. 원본을 그대로 다시 만들지 않게 장면·문장은 새로 쓰라고 지시.
- 샷 길이를 5초 고정에서 2~5초로: `cleanShot` 의 `sec: 5`, `applyScript` 의 `slice(0, 10)`, `addShot` 의 10개 제한, 샷 메뉴의 5/10초 전환, `scoreOf` 의 "샷이 4~8개". 영상 샷은 합칠 때 `ms` 로 잘리므로 클링 5초 영상을 3초로 써도 된다 (`VideoMaker.itemMs`).

## 빌드 방법 (새 컨테이너)

1. Android 명령줄 도구를 받아 `platforms;android-36`, `build-tools;36.0.0`, `platform-tools` 설치 (sdkmanager).
2. `android/local.properties` 에 `sdk.dir=<SDK 경로>`.
3. `cd android && ./gradlew assembleRelease` → `app/build/outputs/apk/release/app-release.apk`.
4. 업데이트마다 `android/app/build.gradle` 의 versionCode +1, versionName 과 `www/js/app.js` 의 `APP_VERSION` 을 같이 올린다. 지금 versionCode 2 / 1.1.0.
